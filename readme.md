# 🌻 Camino de Girasoles

> Que la distancia no sea excusa para no dar flores amarillas 💛

Funciona en **computadora y celular** 📱💻

## ✨ Características
- 📱 Optimizado para teléfonos: toca y desliza para mover el círculo
- ⭐ Estrellas parpadeando
- 🌸 Pétalos cayendo
- 🌻 Girasoles con movimiento suave
- 💌 Mensaje al final
- 🔄 Botón para volver a empezar

## 🚀 Cómo usar en celular
1. Abre el enlace en tu navegador
2. Desliza el dedo por la pantalla → verás el círculo guía
3. Espera a llegar al final 💛
4. Gira el celular y se ajusta solo

## 📂 Estructura
- `index.html` → Página
- `style.css` → Diseño móvil/escritorio
- `script.js` → Animación y toque

## 🎁 Subir a GitHub
1. Nuevo repositorio → `flores-amarillas`
2. Sube los 3 archivos
3. Activa **GitHub Pages** en Settings
4. ¡Abre el enlace desde tu celular! 📱
